NetBox {{ .Chart.AppVersion }} was deployed as {{ .Release.Name }} in namespace {{ .Release.Namespace }}.

{{ if .Values.ingress.enabled -}}
It will be reachable at https://{{ .Values.hostname }} once the Ingress has an
address and cert-manager has issued the certificate into {{ .Values.ingress.tlsSecretName }}:

    kubectl -n {{ .Release.Namespace }} get ingress {{ .Release.Name }}
    kubectl -n {{ .Release.Namespace }} get certificate

{{ else -}}
No Ingress was rendered (ingress.enabled is false). Reach the web service with:

    kubectl -n {{ .Release.Namespace }} port-forward svc/{{ .Values.netbox.fullnameOverride }} 8080:80

{{ end -}}
Log in with the credentials from the `netbox-secrets` Secret:

    kubectl -n {{ .Release.Namespace }} get secret netbox-secrets -o jsonpath='{.data.username}' | base64 -d
    kubectl -n {{ .Release.Namespace }} get secret netbox-secrets -o jsonpath='{.data.password}' | base64 -d

Watch the rollout — the web pod runs the database migrations before it turns ready:

    kubectl -n {{ .Release.Namespace }} rollout status deploy/{{ .Values.netbox.fullnameOverride }}
